# swiggy-on-whatsapp
A WhatsApp AI agent that lets users order food on Swiggy through natural language chat

🍕 Swiggy WhatsApp Ordering Agent
Order food on Swiggy by just sending a WhatsApp message. No app switching, no browsing menus — just chat and your food gets ordered.

💡 The Idea
Most people in India use WhatsApp every day. But ordering food still requires opening a separate app, browsing menus, and going through multiple steps.
This project brings Swiggy directly into WhatsApp — so users can just type what they want and the agent handles the rest.
Example:
User:  "Order me chicken biryani under ₹200"
Bot:   "Found Bawarchi Biryani (4.5⭐) — ₹179. Shall I order?"
User:  "Yes"
Bot:   "✅ Order placed! Arriving in 35 minutes."

🎯 Who Is This For?
* People who find food apps complicated (parents, elders)
* Anyone who wants to order food quickly without switching apps
* Users who want smart suggestions based on budget or diet

⚙️ How It Works
1. User sends a message on WhatsApp
2. AI understands what they want
3. Searches Swiggy for the best match
4. Confirms with the user
5. Places the order

🛠️ Built With
* Python
* Swiggy MCP APIs
* Claude AI (Anthropic)
* WhatsApp Business API
